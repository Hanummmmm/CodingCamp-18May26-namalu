# FocusFlow - Productivity Dashboard 💙

FocusFlow is a simple and modern productivity dashboard built using HTML, CSS, and Vanilla JavaScript.  
This project helps users stay productive with a focus timer, to-do list, quick links, and daily motivation.

---

## ✨ Features

### 🕒 Live Clock & Greeting
- Displays real-time clock and current date
- Dynamic greeting based on time of day

### ⏰ Focus Timer
- Pomodoro-style focus timer
- Start, pause, and reset functionality
- Custom timer options:
  - 15 minutes
  - 25 minutes
  - 50 minutes

### ✅ To-Do List
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Prevent duplicate tasks
- Save tasks using Local Storage

### 📊 Task Progress Bar
- Displays task completion percentage

### 🔗 Quick Links
- Add favorite website links
- Open links instantly
- Save links using Local Storage

### 🌙 Dark Mode
- Toggle light/dark theme
- Theme preference saved automatically

### 💡 Extra Features
- Daily motivational quotes
- Productivity streak display
- Weather display UI
- Smooth animations and hover effects
- Responsive design for mobile and desktop

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
